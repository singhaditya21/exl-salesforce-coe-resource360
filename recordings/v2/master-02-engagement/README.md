# Master 02 recording package

- Coverage: ENG-01 through ENG-08
- Source: authenticated Salesforce Developer Org (`Resource360Hub`)
- Capture method: tab-native frames captured after real Engagement 360 screen-rail selections
- Safety: browser chrome, unrelated tabs and credentials are excluded; the authenticated display name is replaced by `Demo User` in top-level frames
- Narration: macOS Aman voice, English (India)
- Accessibility: WebVTT captions plus MP4 narration audio
- Baseline: `resource360-demo-v2.0-recording`

The opening slide states the purpose and coverage of the video. Each Salesforce scene uses a summary frame and a workbench frame captured from the live org. The live evidence spans 20 engagements, 41 commercial references, 138 accepted allocation records, 20 current budgets, 25 submitted or approved timesheets, 122 work units and milestones, 10 accountable risks or actions, and 138 effective-dated allocation-history rows.
